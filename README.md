# Fraud Detection & Transaction Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Fraud Detection & Transaction Analysis Dashboard** developed using **Microsoft Power BI**.

The objective of the project is to analyze transaction data, identify suspicious activities, detect unusual transaction patterns, and classify transactions based on potential fraud risk.

The dashboard transforms transaction-level data into meaningful fraud-monitoring insights that can help identify high-risk transactions and unusual customer behavior.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall transaction activity
- Identify suspicious transactions
- Detect unusually high transaction amounts
- Identify rapid repeated transactions
- Analyze geographic anomalies
- Create fraud risk classifications
- Identify high-risk transactions
- Analyze fraud trends
- Monitor transaction patterns
- Build an interactive fraud monitoring dashboard

# 🚨 Fraud Risk Analysis

Transactions are analyzed using different risk indicators to identify potentially suspicious activity.

The analysis helps classify transactions into risk levels such as:

- High Risk
- Medium Risk
- Lower / Normal Risk

This allows suspicious transactions to be prioritized for further investigation.

---

# 💰 Unusual Transaction Amounts

Transaction amounts are analyzed to identify unusually large transactions.

High-value transactions may require additional investigation when their behavior differs significantly from normal customer transaction patterns.

The dashboard helps users quickly identify these transactions.

---

# ⚡ Rapid Repeated Transactions

The analysis identifies transactions occurring repeatedly within short periods.

Rapid transaction activity can potentially indicate:

- Duplicate transactions
- Automated transaction attempts
- Unusual purchasing behavior
- Potential fraudulent activity

These transactions can be highlighted for additional review.

---

# 🌍 Geographic Anomaly Analysis

Geographic information is analyzed to identify unusual transaction locations.

This analysis helps detect transactions that may differ from expected customer or transaction behavior.

Geographic visuals provide an easier way to identify suspicious location patterns.

# 🧹 Data Cleaning & Preparation

Before dashboard development, the transaction dataset was cleaned and transformed.

The preparation process included:

- Checking missing values
- Checking duplicate transactions
- Correcting data types
- Standardizing categorical fields
- Validating transaction amounts
- Preparing transaction dates and times
- Checking customer information
- Checking merchant information
- Preparing geographic fields
- Preparing analysis-ready transaction data

Power Query was used to transform and prepare the data before analysis.
